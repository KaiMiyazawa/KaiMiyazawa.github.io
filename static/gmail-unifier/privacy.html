Privacy Policy

最終更新日: 2026年10月1日

Gmail Unifier（以下、「本ツール」）は、開発者本人が自分の複数のGmailアカウントを1つの画面から検索・整理・返信するために作った、個人用のローカルツールです。一般には配布しておらず、開発者本人以外は利用しません。

取得する情報

  • 本人が認可したGmailアカウントのメール・スレッド・下書き・ラベル（Gmail APIを通じて、操作のたびに取得します）
  • Googleが発行する認可トークン

データの保存と利用

本ツールは開発者本人のコンピュータ上だけで動作します。認可トークンはOSの資格情報ストア（macOSのキーチェーンなど）にのみ保存し、メール本文を本ツール側で保存・蓄積することはありません。

取得したデータは、本人の指示によるメールの閲覧・検索・整理・送信のためだけに使います。広告、プロファイリング、機械学習モデルの学習には使いません。

第三者への共有

本ツールの開発者が運営するサーバーはなく、取得したデータを開発者や第三者のサーバーへ送信・共有することはありません。

Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールによるGoogle APIから受け取った情報の利用と他アプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）に従います。

データの削除と認可の取り消し

認可は Googleアカウントのサードパーティ アクセス設定 からいつでも取り消せます。ローカルに保存した認可トークンは、OSの資格情報ストアから削除できます。
